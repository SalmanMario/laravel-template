# laravel-react-template

Starter template: **Laravel 13**, **React 19** + **TypeScript**, **shadcn/ui**, **TanStack Query**, **Router**, **Store** & **Form**, **React Compiler**, **Tailwind CSS 4**, **Vite 8**, Sanctum for the API.

## Requirements

- PHP 8.4+ (8.5 supported)
- Composer 2.10+
- Node.js 22+
- MySQL (or change `DB_CONNECTION` in `.env`)

## Setup

```sh
composer setup
```

This installs the PHP and npm dependencies, creates `.env`, generates the app key, runs the migrations and builds the assets.

## Development

```sh
composer dev
```

This starts the server, the queue worker and Vite. With Laravel Herd the site is already served at `http://<folder-name>.test`, so `npm run dev` is enough. Set `APP_URL` in `.env` to that domain, otherwise Sanctum won't treat requests from the SPA as stateful.

## Structure

- `resources/js/app.tsx`: React entry point (Query client + router), mounted on `#app` in `resources/views/app.blade.php`
- `resources/js/routes/`: TanStack Router file-based routes (`__root.tsx` is the layout); `routeTree.gen.ts` is generated by the Vite plugin
- `resources/js/components/`: React components (`contact-form.tsx` is a TanStack Form example)
- `resources/js/stores/`: global state with TanStack Store (`createStore` + `useSelector`)
- `resources/js/components/ui/`: shadcn/ui components (add more with `npx shadcn@latest add <component>`)
- `resources/js/lib/api.ts`: `fetch` wrapper for the API (session cookie + XSRF token for Sanctum)
- `resources/js/lib/query-client.ts`: the TanStack Query client (defaults for all queries)
- `resources/js/lib/utils.ts`: the `cn()` helper
- `resources/css/app.css`: Tailwind and the shadcn theme
- `routes/web.php`: a catch-all route that serves the SPA for every path except `/api/*` and `/up`
- `routes/api.php`: the API, authenticated with Sanctum (SPA session, or tokens via `HasApiTokens`)
